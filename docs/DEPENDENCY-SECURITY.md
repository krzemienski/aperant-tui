# Dependency Security Posture

Generated by the production audit; re-verify with `npm audit` after any
dependency change.

## Applied (non-breaking, runtime dependencies)

`npm audit fix --package-lock-only` — 8 advisories → 5.

| Package | Before | After | Class |
|---|---|---|---|
| `fast-uri` | 3.1.5 | 3.1.8 | host confusion via skipped IDN canonicalization; SSRF via malformed IPv6 normalization |
| `hono` | 4.13.1 | 4.13.8 | `toSSG()` path escape (incomplete CVE-2026-39408 fix); `parseBody()` memory exhaustion |
| `qs` | 6.15.3 | 6.16.0 | array-limit bypass via bracket-key comma parsing; DoS via attacker-controlled `isBuffer` |

Gates re-run after the change: `npm run typecheck` exit 0, `npm test -w
@aperant/tui` 9/9 exit 0.

## Accepted, not fixed (dev toolchain only)

5 advisories remain, all in the **test toolchain**, none in shipped code:

| Package | Severity | Advisory | Why accepted |
|---|---|---|---|
| `vitest` | critical | arbitrary file read/execute **when the Vitest UI server is listening** | The UI server is never started: the test script is `vitest run` (one-shot, no `--ui`, no watch). |
| `vite` | high | path traversal in optimized-deps `.map` handling; `launch-editor` NTLMv2 disclosure on Windows | Vite is pulled in only as vitest's bundler. No dev server is ever bound — this product is a terminal binary. |
| `esbuild` | moderate | any website can send requests to the **dev server** and read the response | Same: no dev server. esbuild is used headlessly by `tools/build-*.mjs`. |
| `@vitest/mocker`, `vite-node` | moderate | transitive to the above | Same scope. |

The only available remediation is `vitest@5` (major, breaking). That upgrade
rewrites the runner contract for a suite whose green state is load-bearing
proof for the phase-4 verdict, to close advisories that require a listening
dev server this product never starts. Deferred deliberately — not overlooked.

**Re-evaluate when:** the suite is next touched for other reasons, or if any
advisory here gains an exploit path that does not require the UI/dev server.
