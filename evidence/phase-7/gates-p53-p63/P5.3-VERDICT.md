Two prior runs (`evidence/phase-6/run-20260917T160211Z-gates/scratch/gate-p5new-pr-result.json`
and `evidence/phase-6/run-20260917T173809Z-f16-redrive/scratch/F-16-redrive-pr-local-origin-result.json`)

## Decisive observed output
```
$ gh pr list --repo krzemienski/aperant-p53-gate-1789677472 --json number,title,url,state
[{"number":1,"state":"OPEN","title":"Add goodbye function for gate P5.3 verification","url":"https://github.com/krzemienski/aperant-p53-gate-1789677472/pull/1"}]
```
**PR #1 exists on GitHub**, titled from the real commit message (`--fill`,
no fabricated content), state OPEN. `gh pr view 1 ... --json
createdAt,updatedAt` shows `createdAt=2026-09-17T20:51:59Z`,
`updatedAt=2026-09-17T20:52:03Z` — a 4-second gap consistent with the app's
own push-then-`gh pr create` sequence, not a stale or manually-created PR.

`git branch -vv` inside the worktree after the `p` press shows
`feature/gate-p53 b2c6682 [origin/feature/gate-p53] ...` — upstream tracking
was set by the app's own `git push --set-upstream`, independently confirming
the push half landed against the real GitHub remote (not just the `gh pr
create` half).

## Honest limitation: the in-app toast was not captured live
`WorktreeView.tsx`'s `flash()` (via `app-store.ts`) sets a toast for **1800ms**
before clearing it. tuistory's CLI round-trip per `snapshot`/frame poll is on
the same order of magnitude (~150–300ms per call plus process overhead), so
repeated rapid polling after the `p` keypress did not reliably catch the toast
text on screen before it expired — this is a **harness timing limitation**,
not evidence that the app failed to show a message. The screenshot captured
post-action (`step-01-p53-worktree-selected.png`) shows the settled UI state
(worktree selected, diff panel showing the pushed commit) rather than the
transient toast. **GitHub's own state is the decisive proof for this
criterion** ("appears on GitHub"), and that proof is unambiguous: PR #1 is
real, open, and correctly titled.

## Idempotency check (bonus verification)

`createWorktreePR()`'s "already exists" branch
